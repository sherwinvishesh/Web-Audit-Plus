# Decisions

One line of reasoning each. Newest at the bottom of each section.

## Tooling

- **TypeScript 5.9.3, not 7.x.** TS 7 is the native port without the stable JS API; WXT/Vite tooling still expects the classic `typescript` module.
- **lighthouse 13.5.0 pinned explicitly.** npm silently resolved 12.8.2 because of the `node >=22.19` engine field; 13.x is what current Chrome DevTools/PSI run, so parity means 13. We only bundle it, so the engine mismatch on Node 22.17 is harmless.
- **React 18.3.1** as specified, even though 19 is current; `@wxt-dev/module-react` supports both.
- **WXT auto-imports disabled** (`imports: false`): explicit imports make it auditable which files touch `chrome.*` (the Agentic engine must touch none).
- **Global `chrome` + `@types/chrome`** instead of WXT's `browser` wrapper: Chrome-only extension, and `chrome.debugger`/`chrome.sidePanel` are Chrome APIs anyway.
- **Geist + Geist Mono via @fontsource-variable**: Vite bundles the woff2 files into the extension, so the UI makes no external requests.
- **Icons generated by a dependency-free Node script** (zlib PNG encoder) so they are reproducible and need no image tools.
- **Clean `npm install` after incremental installs**: incremental installs dropped rolldown's native binding (npm optional-deps bug); a fresh lockfile fixes it.

## Product

- **Side panel follows the active tab of its window** (global panel + `tabs.onActivated/onUpdated`) rather than per-tab panel instances: one panel, always showing the tab you are looking at.
